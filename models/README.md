# models/

Drop your own turkey model here (`.glb` recommended), host it somewhere your browser
can reach, and put its URL in `CONFIG.modelUrl` inside `shell-turkey-mod.user.js`.
If `modelUrl` is empty, the mod uses a built-in placeholder turkey made of simple shapes.

No third-party model is bundled on purpose: the built-in turkey is generated in code, so
there are no license questions and nothing heavy to download. If you add your own, keep it
low-poly (a few thousand triangles at most) so it doesn't hurt frame rate in full lobbies.
